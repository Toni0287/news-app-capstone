News Application documentation
==============================

A Django news platform where **journalists** write articles and
newsletters, **editors** approve them, and **readers** subscribe to the
publishers and journalists they follow. Approved articles are emailed
to subscribers and are also available through a token-authenticated
REST API.

See ``README.md`` in the project root for how to run the application
with a virtual environment or with Docker.
